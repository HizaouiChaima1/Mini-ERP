# 📡 Module RMI Commun (rmi-common)\n\n**Description** : Interfaces Java RMI partagées pour la communication inter-services \n**Version** : 1.0.0 \n**Groupe Maven** : com.erp \n**Artifact ID** : rmi-common \n\n---\n\n## 📋 Contenu\n\n### Interfaces RMI\n\n#### 1. `StockServiceRmi.java`\n\nInterface RMI pour la gestion du stock.\n\n**Méthodes principales** :\n\n`java\n// Récupérer la quantité d'un produit\nInteger getProductQuantity(Long productId) throws RemoteException;\n\n// Vérifier la disponibilité d'une quantité\nBoolean isProductAvailable(Long productId, Integer quantity) throws RemoteException;\n\n// Réserver une quantité de produit\nBoolean reserveProduct(Long productId, Integer quantity) throws RemoteException;\n\n// Obtenir les informations du produit\nString getProductName(Long productId) throws RemoteException;\nDouble getProductPrice(Long productId) throws RemoteException;\n`\n\n#### 2. `VentesServiceRmi.java`\n\nInterface RMI pour la gestion des ventes.\n\n**Méthodes principales** :\n\n`java\n// Créer une commande\nLong createOrder(String clientName, Double totalAmount, String status) throws RemoteException;\n\n// Gérer le statut d'une commande\nString getOrderStatus(Long orderId) throws RemoteException;\nBoolean updateOrderStatus(Long orderId, String status) throws RemoteException;\n\n// Obtenir les informations de la commande\nDouble getOrderTotal(Long orderId) throws RemoteException;\nInteger countOrdersByClient(String clientName) throws RemoteException;\n`\n\n#### 3. `FinanceServiceRmi.java`\n\nInterface RMI pour la gestion financière.\n\n**Méthodes principales** :\n\n`java\n// Gérer les factures\nLong createInvoice(Long orderId, Double amount, String status) throws RemoteException;\nString getInvoiceStatus(Long invoiceId) throws RemoteException;\nBoolean updateInvoiceStatus(Long invoiceId, String status) throws RemoteException;\nDouble getInvoiceAmount(Long invoiceId) throws RemoteException;\n\n// Gérer les paiements\nLong createPayment(Long invoiceId, Double amount, String paymentMethod) throws RemoteException;\n\n// Obtenir les informations financières\nDouble getTotalOutstandingBalance() throws RemoteException;\n`\n\n---\n\n## 🚀 Installation et utilisation\n\n### 1. Construire le module\n\n`bash\ncd rmi-common\nmvn clean install\n`\n\nCela installe le module dans votre repository Maven local.\n\n### 2. Utiliser le module dans les services\n\nAjouter la dépendance dans le `pom.xml` de chaque service :\n\n`xml\n<dependency>\n    <groupId>com.erp</groupId>\n    <artifactId>rmi-common</artifactId>\n    <version>1.0.0</version>\n</dependency>\n`\n\n### 3. Implémenter les interfaces\n\n**Dans le service Stock** :\n\n`java\npublic class StockServiceRmiImpl extends UnicastRemoteObject implements StockServiceRmi {\n    \n    @Override\n    public Integer getProductQuantity(Long productId) throws RemoteException {\n        // Implémentation\n    }\n    \n    // ...\n}\n`\n\n### 4. Exporter le service\n\n**Configuration Spring** :\n\n`java\n@Configuration\npublic class RmiStockConfiguration {\n    \n    @Bean\n    public RmiServiceExporter stockServiceRmiExporter() throws RemoteException {\n        RmiServiceExporter exporter = new RmiServiceExporter();\n        exporter.setServiceName(\"StockService\");\n        exporter.setServiceInterface(StockServiceRmi.class);\n        exporter.setService(new StockServiceRmiImpl());\n        exporter.setRegistryPort(1099);\n        return exporter;\n    }\n}\n`\n\n### 5. Accéder au service depuis un autre service\n\n**Proxy RMI** :\n\n`java\n@Configuration\npublic class RmiClientConfiguration {\n    \n    @Bean\n    public RmiProxyFactoryBean stockServiceRmiProxy() {\n        RmiProxyFactoryBean rmiProxy = new RmiProxyFactoryBean();\n        rmiProxy.setServiceUrl(\"rmi://stock-service:1099/StockService\");\n        rmiProxy.setServiceInterface(StockServiceRmi.class);\n        return rmiProxy;\n    }\n}\n`\n\n**Utilisation** :\n\n`java\n@Service\npublic class OrderService {\n    \n    @Autowired\n    private StockServiceRmi stockServiceRmi;\n    \n    public void createOrder(Long productId, Integer quantity) throws RemoteException {\n        Boolean available = stockServiceRmi.isProductAvailable(productId, quantity);\n        if (available) {\n            // Créer la commande\n        }\n    }\n}\n`\n\n---\n\n## 🏗️ Architecture des requise\n\n`xml\n<dependency>\n    <groupId>org.springframework</groupId>\n    <artifactId>spring-context-support</artifactId>\n</dependency>\n`\n\nCette dépendance fournit :\n- `RmiServiceExporter` : Exporte les services RMI\n- `RmiProxyFactoryBean` : Crée des proxies pour accéder aux services RMI distants\n\n### Configuration minimale\n\n**Exportation** :\n\n`java\nRmiServiceExporter exporter = new RmiServiceExporter();\nexporter.setServiceName(\"MyService\");\nexporter.setServiceInterface(MyServiceRmi.class);\nexporter.setService(new MyServiceRmiImpl());\nexporter.setRegistryPort(1099);\n`\n\n**Accès** :\n\n`java\nRmiProxyFactoryBean proxy = new RmiProxyFactoryBean();\nproxy.setServiceUrl(\"rmi://localhost:1099/MyService\");\nproxy.setServiceInterface(MyServiceRmi.class);\n`\n\n---\n\n## 🔐 Considérations de sécurité\n\n### 1. Restreindre l'accès RMI\n\n`java\nexporter.setRegistryHost(\"localhost\");  // Seulement local\n`\n\n### 2. Valider les paramètres\n\n`java\n@Override\npublic Boolean isProductAvailable(Long productId, Integer quantity) throws RemoteException {\n    if (productId == null || productId <= 0) {\n        throw new RemoteException(\"Invalid productId\");\n    }\n    if (quantity == null || quantity < 0) {\n        throw new RemoteException(\"Invalid quantity\");\n    }\n    // Logique métier\n}\n`\n\n### 3. Gérer les exceptions\n\n`java\ntry {\n    result = remoteService.someMethod();\n} catch (RemoteException e) {\n    // Erreur RMI - Service indisponible\n    log.error(\"Service RMI indisponible\", e);\n    // Implémenter un fallback\n}\n`\n\n---\n\n## 📈 Performance\n\n### Avantages\n\n✅ **Sérialisation native** : Utilise la sérialisation Java optimisée \n✅ **Pas de conversion JSON** : Communication directe entre objets Java \n✅ **Typage fort** : Détection d'erreurs à la compilation \n✅ **Latence basse** : Appels directs sur le réseau local \n\n### Limitations\n\n⚠️ **Seulement Java** : RMI ne fonctionne qu'avec Java \n⚠️ **Couplage fort** : Services dépendent fortement les uns des autres \n⚠️ **Scalabilité** : Non idéal pour les réseaux distribués mondiaux \n\n---\n\n## 🧪 Tests\n\n### Test unitaire d'une interface RMI\n\n`java\n@Test\npublic void testStockServiceRmiInterface() throws RemoteException {\n    StockServiceRmi service = new StockServiceRmiImpl();\n    \n    // Tester une méthode\n    Integer quantity = service.getProductQuantity(1L);\n    assertNotNull(quantity);\n}\n`\n\n### Test d'intégration RMI\n\n`java\n@RunWith(SpringRunner.class)\n@SpringBootTest\npublic class RmiIntegrationTest {\n    \n    @Autowired\n    private StockServiceRmi stockServiceRmi;
